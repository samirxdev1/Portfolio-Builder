CHAPTER 1 — Introduction to Data Structures

Q1. Define a data structure. Explain its importance.

Definition: A data structure is a systematic way of organizing and storing data in computer memory so that it can be used efficiently. Some common ones are array, linked list, stack, queue, tree, graph and hash table.

Algorithm + Data Structure = Program

Importance

  1. Fast searching – With 10⁶ (1 million) items, scanning one by one every time is slow. If data is organized well (sorted, tree, hash), we don't need to look at every item.
  2. Handles large data – Processors are fast, but with billions of records even a fast processor slows down. A good structure reduces the work.
  3. Handles many requests – Thousands of users may search a web server at once; efficient structures keep the server responsive.
  4. Efficient memory use – The right structure stores data with less wasted space.
  5. Reusability & clarity – Ready-made structures (stack, queue, etc.) can be reused across programs.
  6. Applications – Compiler design, operating systems, DBMS, AI, graphics, simulation, numerical analysis.

Characteristics of a good data structure: Correctness (operations work correctly), Time complexity (as small as possible), Space complexity (as little memory as possible).

Q2. Define an algorithm and state its characteristics.

Definition: An algorithm is a finite set of well-defined instructions that is followed to solve a particular problem in a finite amount of time.

Characteristics (5 properties)

Property Meaning Example
Finiteness Must end after a finite number of steps "Add two numbers" ends after printing the sum; a loop with no exit is not an algorithm
Definiteness Every step is clear, no ambiguity "Divide N by 2" is definite; "divide N by some number" is not
Input Zero or more values given before it starts Numbers a and b in an addition algorithm
Output At least one result is produced The sum a + b
Effectiveness Each step is simple/feasible enough to be carried out and coded in any language Using +, -, *, /; not "find the best number"

Example (add two numbers): Step 1 Start → Step 2 Read a, b → Step 3 sum = a + b → Step 4 Print sum → Step 5 Stop.

Q9. Time complexity and space complexity

Time complexity – A function describing the amount of time an algorithm takes in terms of the size of its input (n). It is the running time of the program.

Space complexity – A function describing the amount of memory an algorithm needs in terms of the input size. It has two parts:

  • Fixed part – space for instructions, constants, simple variables (independent of input).
  • Variable part – space that depends on input: recursion stack, dynamically allocated memory.

Example 1 – sum of n numbers stored in an array

sum = 0;
for (i = 0; i < n; i++)
    sum = sum + a[i];
  • Time: the loop runs n times → O(n)
  • Space: only sum and i extra → O(1) (besides the array itself)

Example 2 – recursive factorial fact(n) calls itself n times → time O(n), and the recursion stack grows to n levels → space O(n).

Q10. Linear and non-linear data structures

Linear: Elements are connected one after another in a sequence; each element has a previous and a next element, and data is processed sequentially. Examples: Array, Stack, Queue, Linked list.

Non-linear: Elements are not arranged in a sequence; one element can be connected to many others. Examples: Tree, Graph.

CHAPTER 2 — Arrays & Linked Lists

Q1. Define an array. State any two advantages.

Definition: An array is a collection of similar data elements (same data type) stored in consecutive memory locations and referred to by an index (subscript).

Declaration: type name[size]; → e.g. int marks[5];

Two advantages

  1. Direct (random) access – any element A[i] is reached in O(1) time using its index.
  2. Easy to use/traverse – one name for many values; a single loop can process all elements. Also uses less memory overhead than a linked list and has better cache performance.

Q2. Linear array with an example

A linear (one-dimensional) array stores elements in a single row, one after another, accessed with one subscript.

int Age[5] = {2, 5, 3, 1, 7};
Index (subscript) 0 1 2 3 4
Value 2 5 3 1 7
Address (BA = 1000, w = 2) 1000 1002 1004 1006 1008
  • Length = upper_bound − lower_bound + 1 = 4 − 0 + 1 = 5
  • Address of A[k] = BA + w × (k − lower_bound). e.g. Age[3] = 1000 + 2×(3 − 0) = 1006

Ways to store values: (1) initialize at declaration int a[3] = {98,97,90}; (unassigned elements become 0), (2) read from keyboard using a loop, (3) assign individually a[0] = 10;.

Q3. Insertion of an element into an array — all cases

Insertion = adding a new element at a given position.

Case What happens Shifting?
At the end A[n] = item; n = n + 1 None
At the beginning Every element moves one place right, item placed at index 0 All n elements
In the middle (position pos) Elements from pos onward move one place right; item goes to A[pos-1] (n − pos + 1) elements
Array full (n = MAX) Insertion not possible → overflow (unless array is resized) –

Algorithm (insert item at position pos)

  1. Read n, the elements, pos and item
  2. If pos < 1 or pos > n + 1 → "Invalid position", stop
  3. If n == MAX → "Overflow", stop
  4. Repeat for i = n down to pos: A[i] = A[i-1] (shift right)
  5. A[pos-1] = item
  6. n = n + 1
  7. Display array, Stop

Example: A = {10, 20, 30, 40}, insert 25 at position 3

Before : 10 20 30 40
Shift  : 10 20 __ 30 40      (30, 40 move right)
After  : 10 20 25 30 40

Q4. Deletion of an element from an array — all cases

Deletion = removing an element from a position and reducing the size by 1.

Case What happens Shifting?
Last element Just n = n − 1 None
First element All remaining elements shift one place left n − 1 elements
Middle (position pos) Elements after pos shift one place left to fill the gap (n − pos) elements
Empty array (n = 0) Nothing to delete → underflow –

Algorithm (delete element at position pos)

  1. Read n, the elements and pos
  2. If n == 0 → "Array is empty", stop
  3. If pos < 1 or pos > n → "Invalid position", stop
  4. Repeat for i = pos to n − 1: A[i-1] = A[i] (shift left)
  5. n = n − 1
  6. Display array, Stop

Example: A = {10, 20, 30, 40, 50}, delete position 2

Before : 10 20 30 40 50
Shift  : 10 30 40 50          (30, 40, 50 move left)
After  : 10 30 40 50   (n = 4)

Q5. Multidimensional array — example

A multidimensional array has more than one subscript. The most common is the two-dimensional (2-D) array — data stored in rows and columns like a table/matrix.

Declaration: data_type array_name[rows][columns];

int marks[3][4];                    // 3 rows, 4 columns = 12 elements
int A[2][3] = { {1, 2, 3},
                {4, 5, 6} };        // row 0 = {1,2,3}, row 1 = {4,5,6}

Access with two subscripts: A[1][2] → 6 (row 1, column 2).

Memory representation – memory is linear, so a 2-D array is stored either

  • Row-major: row by row → Address of A[i][j] = BA + w·(n·i + j) (n = number of columns)
  • Column-major: column by column → Address of A[i][j] = BA + w·(m·j + i) (m = number of rows)

(When lower bounds are not 0: BA + w[n(i − lr) + (j − lc)] for row-major.)

Uses: matrices (transpose, sum, difference, product), tables, images.

Q6. A[3][4], base address 1000, 2 bytes per element — address of A[2][3] (row-major)

Given: m = 3 rows, n = 4 columns, BA = 1000, w = 2, i = 2, j = 3 (indices start at 0)

Address of A[i][j] = BA + w × (n × i + j)
A[2][3]            = 1000 + 2 × (4 × 2 + 3)
                   = 1000 + 2 × 11
                   = 1000 + 22
                   = 1022

Answer: 1022

Q8. Define a linked list; structure of a node

Linked list: A linear collection of data elements called nodes, where the order is given by pointers. Nodes are not stored in consecutive memory locations; each node holds the address of the next node.

Node structure – two parts:

  1. Data – the information stored.
  2. Link / next – address of the next node (NULL in the last node).
struct node {
    int data;             // information part
    struct node *next;    // link part (address of next node)
};

 head
  │
  ▼
┌──────┬──────┐   ┌──────┬──────┐   ┌──────┬──────┐
│  10  │  ●───┼──►│  20  │  ●───┼──►│  30  │ NULL │
└──────┴──────┘   └──────┴──────┘   └──────┴──────┘
 data   next       data   next       data   next

head is a special pointer holding the address of the first node; if the list is empty, head = NULL.

Advantages: dynamic size, efficient memory use, easy insertion/deletion. Disadvantages: extra memory for pointers, searching is slow (no direct access).

Q10. Traversal of a singly linked list

Traversal = visiting every node exactly once, starting from head, to display/count/process data. A linked list has no index, so each node is reached by following the next pointer. A temporary pointer temp is used so that head is never lost. Traversal stops when temp becomes NULL.

Algorithm

  1. temp = head
  2. Repeat steps 3–4 while temp != NULL
  3. Display temp->data
  4. temp = temp->next
  5. Stop
head → [10|●]→[20|●]→[30|NULL]      temp visits 10, 20, 30, then NULL → stop

Time complexity: O(n).

Q11. Dynamic memory allocation in a linked list — malloc, calloc

Static memory is reserved at compile time (e.g. int a[20] always reserves 20 elements). Dynamic memory is allocated at run time from the heap, only when needed, and accessed only through pointers. A linked list is built dynamically — every new node is created with malloc(), and freed when deleted.

Function Purpose
malloc() Allocates one block of given size (bytes); memory is uninitialized (garbage). Returns void *, or NULL if memory is not available
calloc() Allocates multiple blocks and initializes all to zero
realloc() Changes the size of a previously allocated block (may move it)
free() Releases (deallocates) the memory back to the heap 
ptr = (int *) malloc(5 * sizeof(int));     // syntax: ptr = (type *) malloc(size);
ptr = (int *) calloc(5, sizeof(int));      // syntax: ptr = (type *) calloc(n, size);
ptr = (int *) realloc(ptr, 10 * sizeof(int));
free(ptr);

malloc vs calloc: malloc takes 1 argument (total bytes), calloc takes 2 (count, size); malloc leaves garbage values, calloc zeroes the memory; malloc is marginally faster.

Creating a node:

struct node *newNode = (struct node *) malloc(sizeof(struct node));
newNode->data = 10;
newNode->next = NULL;

Using a freed pointer (dangling pointer) or freeing twice causes undefined behaviour.

Q12. Insertion in a singly linked list — beginning, end, given position

Only pointers change; no shifting of nodes is needed.

(1) At the beginning

  1. Allocate newNode; set newNode->data = item
  2. newNode->next = head
  3. head = newNode
Before: head → [10]→[20]→NULL          Insert 5
After : head → [5]→[10]→[20]→NULL

(2) At the end

  1. Allocate newNode; newNode->data = item; newNode->next = NULL
  2. If head == NULL → head = newNode, stop
  3. temp = head; while temp->next != NULL: temp = temp->next
  4. temp->next = newNode
Before: head → [10]→[20]→NULL          Insert 30
After : head → [10]→[20]→[30]→NULL

(3) At a given position pos

  1. Allocate newNode; newNode->data = item
  2. If pos == 1: newNode->next = head; head = newNode; stop
  3. temp = head; move temp forward until it points to node number pos − 1
  4. newNode->next = temp->next
  5. temp->next = newNode (order matters — link the new node first, then break the old link)
Before: head → [10]→[20]→[40]→NULL     Insert 30 at position 3
temp stops at 20 (pos−1 = 2)
After : head → [10]→[20]→[30]→[40]→NULL

Q13. Deletion from a singly linked list — beginning, end, given position

Deleted nodes must be released with free().

(1) From the beginning

  1. If head == NULL → "List is empty", stop
  2. temp = head
  3. head = head->next
  4. free(temp)

(2) From the end

  1. If head == NULL → "List is empty", stop
  2. If head->next == NULL (one node) → free(head); head = NULL; stop
  3. temp = head; prev = NULL
  4. While temp->next != NULL: prev = temp; temp = temp->next
  5. prev->next = NULL
  6. free(temp)

(3) From a given position pos

  1. If head == NULL → "List is empty"
  2. If pos == 1 → delete first node (as above)
  3. temp = head; move to node pos − 1
  4. If temp == NULL or temp->next == NULL → "Invalid position"
  5. toDelete = temp->next
  6. temp->next = toDelete->next (bypass the node)
  7. free(toDelete)
Before: head → [10]→[20]→[30]→NULL      Delete position 2
After : head → [10]→[30]→NULL           (node 20 freed)

Q14. Circular linked list and doubly linked list

Circular linked list

A linked list in which the last node points back to the first node (head) instead of NULL, forming a circle. Can be singly or doubly circular. Traversal stops when the pointer returns to head (not when it becomes NULL).

   ┌────────────────────────────────────┐
   ▼                                    │
 head → [10|●]→[20|●]→[30|●]────────────┘
  • Advantages: any node can be the starting point; ideal for round-robin CPU scheduling and turn-based games; queue implementation is easy.
  • Disadvantages: traversal needs care to avoid infinite loops; reversing is harder.

Doubly linked list

Each node has three parts: prev pointer, data, next pointer. It can be traversed forward and backward. prev of the first node and next of the last node are NULL.

struct dnode {
    struct dnode *prev;
    int data;
    struct dnode *next;
};

NULL ◄─[prev|10|next]◄──►[prev|20|next]◄──►[prev|30|next]─► NULL
  • Advantages: two-way traversal; deleting a given node is easier (previous node is directly reachable); flexible searching from either end.
  • Disadvantages: extra memory for the prev pointer; insertion/deletion must update both pointers, so it is more complex.

Q15. C program to insert an element at a specified position in an array

Logic: shift every element from the position onward one place to the right, then store the new element and increase n.

#include <stdio.h>
#define MAX 100

int main() {
    int a[MAX], n, pos, item, i;

    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    printf("Enter position (1 to %d): ", n + 1);
    scanf("%d", &pos);
    printf("Enter element to insert: ");
    scanf("%d", &item);

    if (n == MAX) {
        printf("Overflow: array is full\n");
    } else if (pos < 1 || pos > n + 1) {
        printf("Invalid position\n");
    } else {
        for (i = n; i >= pos; i--)      /* shift right */
            a[i] = a[i - 1];
        a[pos - 1] = item;              /* insert */
        n++;
        printf("Array after insertion: ");
        for (i = 0; i < n; i++)
            printf("%d ", a[i]);
        printf("\n");
    }
    return 0;
}

Sample run: n = 3, elements 10 20 30, position 2, element 25 → 10 25 20 30.

Q16. C program to delete an element from a specified position in an array

Logic: shift every element after the position one place to the left, then decrease n.

#include <stdio.h>
#define MAX 100

int main() {
    int a[MAX], n, pos, i;

    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    if (n == 0) {
        printf("Underflow: array is empty\n");
        return 0;
    }
    printf("Enter position to delete (1 to %d): ", n);
    scanf("%d", &pos);

    if (pos < 1 || pos > n) {
        printf("Invalid position\n");
    } else {
        for (i = pos; i < n; i++)       /* shift left */
            a[i - 1] = a[i];
        n--;
        printf("Array after deletion: ");
        for (i = 0; i < n; i++)
            printf("%d ", a[i]);
        printf("\n");
    }
    return 0;
}

Sample run: 10 20 25 30 40, delete position 2 → 10 25 30 40.

Q18. Insertion at the beginning and end of a singly linked list (3-mark answer)

At the beginning

  1. Create newNode with malloc, store the data.
  2. newNode->next = head
  3. head = newNode
newNode->next = head;
head = newNode;

Time: O(1) — no traversal, no shifting.

At the end

  1. Create newNode, store data, set newNode->next = NULL.
  2. If list is empty, head = newNode.
  3. Otherwise move temp from head until temp->next == NULL.
  4. temp->next = newNode
while (temp->next != NULL) temp = temp->next;
temp->next = newNode;

Q19. Deletion at the beginning and end of a singly linked list (3-mark answer)

From the beginning

  1. If head == NULL → list empty.
  2. temp = head; head = head->next; free(temp);

From the end

  1. If head == NULL → list empty. If only one node → free(head); head = NULL;

#include <stdlib.h>

    struct node *next;
};

            return 1;

        scanf("%d", &value);
        newNode->data = value;
        newNode->next = NULL;

        if (head == NULL)               /* first node */
            head = newNode;
        else
            tail->next = newNode;       /* link at the end */
        tail = newNode;
    }

    printf("Linked list: ");

        temp = temp->next;

    while (head != NULL) {

        head = head->next;

    }

CHAPTER 3 — Stack and Queue

Q1. Define a stack. Why is it called a LIFO data structure?

Definition: A stack is a linear data structure in which elements are added and removed only from one end, called the TOP.

LIFO – Last-In-First-Out: the element inserted last is the first one to be removed. Think of a pile of plates: you place a plate on top and you also take a plate from the top; the plate placed first stays at the bottom until all others are removed.

        ┌────┐
 TOP ─► │ 30 │  ← inserted last, removed first
        ├────┤
        │ 20 │
        ├────┤
        │ 10 │  ← inserted first, removed last
        └────┘

Array representation: a stack is stored in an array STACK[MAX] with a variable TOP.

  • TOP = -1 → stack is empty
  • TOP = MAX − 1 → stack is full (because array indices start at 0)

Q2. What is stack overflow? When does it occur?

Stack overflow is the error condition that arises when we try to push (insert) an element into a stack that is already full.

  • Occurs when TOP == MAX − 1 and a PUSH is attempted.
  • Example: MAX = 5, stack holds 5 elements, TOP = 4. Pushing a 6th element → "Stack Overflow"; the element is not inserted.

Q3. What is stack underflow? When does it occur?

Stack underflow is the error condition that arises when we try to pop (delete) an element from an empty stack.

  • Occurs when TOP == −1 and a POP (or PEEK) is attempted.
  • Example: a newly created stack has no elements; calling POP gives "Stack Underflow" because there is nothing to remove.

Q4. Basic operations on a stack — push, pop and peek

Operation Purpose
PUSH Insert an element at the top
POP Remove (and return) the top element
PEEK Return the top element without removing it

PUSH(STACK, ITEM)

  1. Start
  2. If TOP == MAX − 1 → display "Stack Overflow", go to step 6
  3. TOP = TOP + 1
  4. STACK[TOP] = ITEM
  5. Display "Element inserted into stack"
  6. Stop

POP(STACK)

  1. Start
  2. If TOP == −1 → display "Stack Underflow", go to step 6
  3. ITEM = STACK[TOP]
  4. TOP = TOP − 1
  5. Display ITEM
  6. Stop

PEEK(STACK)

  1. Start
  2. If TOP == −1 → display "Stack is Empty", go to step 5
  3. ITEM = STACK[TOP]
  4. Display ITEM
  5. Stop

Example (MAX = 5, initially empty, TOP = −1)

Step Operation Stack (bottom → top) TOP
1 PUSH 10 10 0
2 PUSH 20 10, 20 1
3 PUSH 30 10, 20, 30 2
4 PEEK 10, 20, 30 → returns 30 (stack unchanged) 2
5 POP 10, 20 → returns 30 1
6 POP 10 → returns 20 0
7 POP empty → returns 10 −1
8 POP Underflow −1

All three operations take O(1) time.

Q2. Define sorting. State its importance.

Sorting is the process of arranging the data items of a data structure in a particular order — ascending (small → large) or descending (large → small).

Importance

  1. Makes searching much faster (binary search works only on sorted data).
  2. Makes data easier to analyse, compare and present (rank lists, merit lists, dictionaries).
  3. Helps in merging two lists and finding duplicates, minimum/maximum, median easily.
  4. Improves the overall efficiency of database and other applications.

Q5. Sequential (linear) search — algorithm and example

Idea: check each element from the first to the last, in order, until the key is found or the list ends. Works on sorted and unsorted data.

Algorithm

  1. Read n, array A and the key
  2. Set i = 0
  3. Repeat steps 4–5 while i < n
  4. If A[i] == key → display "Found at position i+1" and stop
  5. i = i + 1
  6. If the loop ends → display "Not found"
  7. Stop

Example: A = {12, 45, 3, 67, 21, 9}, key = 67

i=0: 12 ≠ 67   i=1: 45 ≠ 67   i=2: 3 ≠ 67   i=3: 67 == 67 → found at index 3 (position 4)

Complexity: best O(1), average O(n), worst O(n) (key at end or absent). Space O(1).

Q6 & Q8. Binary search — algorithm and example (Q6 and Q8 are the same question)

Idea: works only on a sorted array. Compare the key with the middle element; if smaller, search the left half; if larger, search the right half; repeat until found or the range is empty.

Algorithm

  1. Set low = 0, high = n − 1
  2. Repeat while low ≤ high
  3. mid = (low + high) / 2
  4. If A[mid] == key → found at mid, stop
  5. Else if A[mid] < key → low = mid + 1
  6. Else → high = mid − 1
  7. If the loop ends → "Not found"

Example: A = {4, 10, 15, 22, 30, 45, 55}, key = 30

Step low high mid a[mid] Decision
1 0 6 3 22 30 > 22 → right half
2 4 6 5 45 30 < 45 → left half
3 4 4 4 30 Found at index 4

Complexity: best O(1), average/worst O(log n).

Q7. C program to implement sequential search

    int i;
    for (i = 0; i < n; i++) {
        if (a[i] == key)
            return i;           /* found: return index */
    }
    return -1;                  /* not found */
}

        scanf("%d", &a[i]);

Q9. Bubble Sort — algorithm and example

Working: Adjacent elements are compared and swapped if in the wrong order. Repeating this for every pair makes the largest element "bubble up" to the end in each pass. Passes continue until no swap is needed.

Algorithm

  1. Read n and array A
  2. For i = 0 to n − 2
  3.   For j = 0 to n − i − 2
  4.     If A[j] > A[j+1] → swap A[j] and A[j+1]
  5. Display the sorted array

Example: [5, 2, 9, 1, 6]

Pass 1: 2 5 1 6 9     (9 bubbles to the end)
Pass 2: 2 1 5 6 9
Pass 3: 1 2 5 6 9     (sorted)

Complexity: worst & average O(n²); best O(n) (already sorted, when a "swapped" flag stops the loop early). Space O(1).

Q10. Selection Sort — algorithm and example

Working: The array is split into a sorted part (left) and unsorted part (right). In each pass select the smallest element of the unsorted part and swap it with the first element of the unsorted part; the boundary moves one step right.

Algorithm

  1. For i = 0 to n − 2
  2.   min = i
  3.   For j = i + 1 to n − 1: if A[j] < A[min] then min = j
  4.   Swap A[i] and A[min]
  5. Display sorted array

Example: [29, 10, 14, 37, 13]

Pass 1: smallest 10 ↔ index 0  → 10 29 14 37 13
Pass 2: smallest 13 ↔ index 1  → 10 13 14 37 29
Pass 3: smallest 14 (in place) → 10 13 14 37 29
Pass 4: smallest 29 ↔ index 3  → 10 13 14 29 37   ✔ sorted

Complexity: O(n²) in best, average and worst case (always scans the rest). Space O(1).

Q11. Insertion Sort — algorithm and example

Working: Builds the sorted array one element at a time — like sorting playing cards in your hand. Take the next element (key) and insert it at its correct place among the already sorted elements on its left, shifting larger ones right.

Algorithm

  1. For i = 1 to n − 1
  2.   key = A[i], j = i − 1
  3.   While j ≥ 0 and A[j] > key: A[j+1] = A[j]; j = j − 1
  4.   A[j+1] = key
  5. Display sorted array

Example: [12, 11, 13, 5, 6]

Step key Action Array
1 11 shift 12, insert before it 11 12 13 5 6
2 13 already in place 11 12 13 5 6
3 5 shift 13, 12, 11; insert at start 5 11 12 13 6
4 6 shift 13, 12, 11; insert after 5 5 6 11 12 13

Complexity: worst & average O(n²); best O(n) (already sorted). Good for small or nearly-sorted data.

Q12. Quick Sort and the partition operation

Quick Sort is a divide-and-conquer algorithm.

  1. Choose a pivot element (here: the last element).
  2. Partition: rearrange so that all elements smaller than the pivot go to its left and larger ones to its right. The pivot is now in its final sorted position.
  3. Recursively apply the same steps to the left and right sub-arrays.

Partition operation (pivot = last element): keep an index i = low − 1. Scan j from low to high − 1; whenever A[j] < pivot, do i++ and swap A[i] with A[j]. Finally swap A[i+1] with the pivot and return i + 1.

Example: [10, 80, 30, 90, 40, 50, 70], pivot = 70

j A[j] A[j] < 70? Action Array
0 10 yes i=0, swap with itself 10 80 30 90 40 50 70
1 80 no – 10 80 30 90 40 50 70
2 30 yes i=1, swap A[1]↔A[2] 10 30 80 90 40 50 70
3 90 no – 10 30 80 90 40 50 70
4 40 yes i=2, swap A[2]↔A[4] 10 30 40 90 80 50 70
5 50 yes i=3, swap A[3]↔A[5] 10 30 40 50 80 90 70
end – – swap A[i+1]=A[4] with pivot 10 30 40 50 70 90 80

Pivot 70 is now at its final position (index 4). Left part [10,30,40,50] and right part [90,80] are sorted the same way →

Sorted: 10, 30, 40, 50, 70, 80, 90

Complexity: best & average O(n log n); worst O(n²) (already sorted or reverse-sorted input with a bad pivot).

Q13. Merge Sort — basic working steps

Merge Sort is a divide-and-conquer algorithm.

  1. Divide – split the array into two halves, repeatedly, until each part has one element (a single element is already sorted).
  2. Conquer/Merge – merge two sorted halves into one sorted array by comparing the front elements of both halves and taking the smaller each time.
  3. Keep merging upward until one sorted array remains.

Example: [38, 27, 43, 3, 9, 82, 10]

Divide:
            [38 27 43 3 | 9 82 10]
        [38 27 | 43 3]      [9 82 | 10]
      [38][27] [43][3]      [9][82]  [10]

Merge:
      [27 38] [3 43]        [9 82]   [10]
        [3 27 38 43]          [9 10 82]
            [3 9 10 27 38 43 82]      ✔ sorted

Complexity: O(n log n) in best, average and worst case (needs extra O(n) space for the temporary halves).

Q14. C program to implement Bubble Sort

#include <stdio.h>

void bubbleSort(int a[], int n) {
    int i, j, temp, swapped;
    for (i = 0; i < n - 1; i++) {
        swapped = 0;
        for (j = 0; j < n - i - 1; j++) {
            if (a[j] > a[j + 1]) {          /* compare adjacent */
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;            /* swap */
                swapped = 1;
            }
        }
        if (swapped == 0)                   /* already sorted */
            break;
    }
}

int main() {
    int a[100], n, i;

    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    bubbleSort(a, n);

    printf("Sorted array: ");
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
    return 0;
}

Sample run: 64 34 25 12 22 11 90 → 11 12 22 25 34 64 90. The swapped flag stops early once a pass makes no swap, giving the O(n) best case.

Q7. Purpose of malloc(), calloc(), realloc(), free()

  • malloc(size) – allocates a single block of size bytes from the heap; contents are uninitialized (garbage); returns a pointer or NULL on failure.
  • calloc(n, size) – allocates n blocks of size bytes each and sets all bytes to zero.
  • realloc(ptr, new_size) – changes the size of an already allocated block; existing data is preserved; the block may move to a new address.
  • free(ptr) – releases the memory back to the heap so that it can be reused; using a pointer after freeing (dangling pointer) or freeing twice is an error.

Q8. Creation of a singly linked list — step by step

  1. Declare head = NULL (an empty list).
  2. Allocate memory for a new node: newNode = (struct node *) malloc(sizeof(struct node));
  3. Read the value and store it: newNode->data = value;
  4. Set newNode->next = NULL;
  5. If head == NULL → head = newNode (first node).
  6. Otherwise traverse to the last node and set last->next = newNode.
  7. Repeat steps 2–6 for every element.
  8. Stop.
Step 1: head → NULL

Q14. C program to traverse and display all elements of a singly linked list

#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

/* creates a node and adds it at the end */
struct node *addNode(struct node *head, int value) {
    struct node *newNode = (struct node *) malloc(sizeof(struct node));
    struct node *temp;
    newNode->data = value;
    newNode->next = NULL;
    if (head == NULL)
        return newNode;
    temp = head;
    while (temp->next != NULL)
        temp = temp->next;
    temp->next = newNode;
    return head;
}

/* traverses the list and displays every element */
void traverse(struct node *head) {
    struct node *temp = head;
    int count = 0;
    if (head == NULL) {
        printf("List is empty\n");
        return;
    }
    printf("Elements: ");
    while (temp != NULL) {          /* stop when NULL is reached */
        printf("%d -> ", temp->data);
        temp = temp->next;          /* move to next node */
        count++;
    }
    printf("NULL\n");
    printf("Total nodes = %d\n", count);
}

int main() {
    struct node *head = NULL;
    int n, i, value;

    printf("Enter number of nodes: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        printf("Enter value: ");
        scanf("%d", &value);
        head = addNode(head, value);
    }
    traverse(head);
    return 0;
}

Sample run: 10 20 30 → Elements: 10 -> 20 -> 30 -> NULL, Total nodes = 3.

Q1. Define searching. Need for searching in data structures

Searching is the process of finding the location of a given element (the key) in a collection of data, or deciding that it is not present. The result is either the position of the element (successful) or a "not found" message (unsuccessful). Common techniques: sequential (linear) search and binary search.

Need for searching

  1. Data is stored to be retrieved – searching is how we get it back (find a student's record, a contact, a product).
  2. Large data (10⁶ items) cannot be scanned slowly every time; efficient searching saves time.
  3. Many operations depend on it — insertion (check duplicates), deletion (find the item first), updation.
  4. Used in databases, operating systems, compilers, web search and every application handling data.
  5. The choice of data structure and search method decides speed: e.g. binary search on sorted data is O(log n) instead of O(n).

Q10. C program for Selection Sort

Logic: for each position i, find the index min of the smallest element in a[i..n-1] and swap it with a[i].

#include <stdio.h>

void selectionSort(int a[], int n) {
    int i, j, min, temp;
    for (i = 0; i < n - 1; i++) {
        min = i;                            /* assume first unsorted is smallest */
        for (j = i + 1; j < n; j++) {
            if (a[j] < a[min])
                min = j;                    /* remember index of smallest */
        }
        temp = a[i];                        /* swap smallest with a[i] */
        a[i] = a[min];
        a[min] = temp;
    }
}

int main() {
    int a[100], n, i;

    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);

    selectionSort(a, n);

    printf("Sorted array: ");
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
    return 0;
}

Sample run: 45 20 35 10 50 25 → 10 20 25 35 45 50.
